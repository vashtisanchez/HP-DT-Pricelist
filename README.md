# HP Desktop Pricelist (Iontech × HP)

Dealer and sales reference for HP Consumer Desktops.

- `index.html` – dealer / sales team view (read only)
- Editable view lives in the `HP-DT-Pricelist-admin` repository. Click **Download data.js** there and upload it here to publish.

## Updating
| What | How |
|---|---|
| Prices / specs | Open the admin site, edit or import `HP-DT PL.xlsx`, download `data.js`, upload it to this repo (replace). |
| Product image | Upload to `images/` named by part number, e.g. `images/EM9K6PA.png` (webp, png, jpg, avif). |
| Spec sheet | Upload to `specs/` as `<PART NUMBER> Spec Sheet.pdf`. |
| Promo | Upload the image to `promos/`, add it on the Promos tab in the admin site, download and upload `data.js`. |
